# Limitations (v0.7)

This is a working public extract, not a complete mechanistic-interpretability suite.

- **Heuristic glosses.** English is keyword/example based unless you inject an LLM client. A fluent sentence is not extra evidence.
- **No logit lens / SAE zoo.** The alphabet is clustering on observation embeddings, hashed n-grams, or a deterministic local word-sentence SVD of one text file. Logit lens is the next slice on [docs/ROADMAP.md](docs/ROADMAP.md) and is still unstarted. A higher majority-topic purity on that SVD does not make a code a next-token predictor. An SAE zoo stays later. Neither ships in this version.
- **No hub runtime.** `neuralese adapt` reads hidden-state dumps (`.npy`, `.npz`, `.jsonl`), including the stacked shape of a HuggingFace `hidden_states` tuple. It does not download weights or run a model.
- **Prose is hashed text, not a hidden state.** [examples/prose_corpus](examples/prose_corpus) is 320 original sentences. `learn` embeds them with the default 32-d character trigram hash (`--n-symbols 8 --seed 0`). Default `tau_residual` 0.55 and `tau_kappa` 0.35 hold for that file (residual about 0.422, mean kappa about 0.906). Each topic repeats one workplace sentence (`anchors.json`). The varied sentences alone, under that same hash, miss the default residual (about 0.771, mean kappa about 0.636, majority-topic purity about 0.31) and are not certified. `neuralese report` prints the measurement. It does not relax `certify`.
- **Varied prose uses a separate local encoder.** [examples/varied_prose](examples/varied_prose) is the same sentences with the repeated workplace line removed and no shared suffix added. `learn --encoder word_sentence_svd --n-symbols 8 --seed 0` builds a deterministic TF-IDF word-sentence SVD from the texts in that file, after the fixed Glasgow IR English stop list (`FUNCTION_WORDS`, used whole, plus `did` and `does`). It is not a model hidden state. The SVD width is `n_symbols`. Library thresholds were not lowered. That run certifies (residual about 0.439, mean kappa about 0.904, 8 live). Majority-topic purity is a diagnostic, available on `neuralese report --topics` and not a certify gate: unweighted mean about 0.757, size-weighted about 0.725 (232 of 320). The lowest live cluster is pottery-majority, 31 of 55, purity about 0.564. The bakery-majority cluster is 32 of 46, purity about 0.696. Every live cluster on this run is at or above 0.5. A cluster under 0.5 would be called mixed. The geometry is decodable and still only partly topical. Hashed trigrams remain the default, and they still reject this file. The basis is fit to the file in hand. It is not a frozen encoder for a new document. The v0.6 stop list left a bakery-majority cluster at purity 0.40; that figure is the previous encoder, not this one.
- **Checked-in activation stack is still a hash of the prose.** [examples/activation_stack](examples/activation_stack) is `hidden_states.npz`, shape `(3, 320, 32)`, layout `hf_layers`. `export_hidden_states.py` builds it from the prose rows. Layer 0 is the same 32-d character trigram hash. `adapt --layout hf_layers --layer 0 --pool last`, then `learn --n-symbols 8 --seed 0`, certifies at the library defaults (residual about 0.422, mean kappa about 0.906). It is not a model dump. Layers 1 and 2 (word unigrams, and their normalized sum) are not that published command. Stripping the workplace anchor still fails the default residual on this hash. The varied-prose SVD encoder is a different path.
- **Toy fixtures stay toys.** `examples/toy_stream`, `examples/public_domain`, and `examples/mdl_delta` are unit fixtures. The public-domain file uses hand-placed 8-d near-orthogonal vectors. They are not the prose result and they are not the activation stack.
- **Reservoir is part of the seal.** Packs store the observations used at mint time and `certify` recomputes prototypes from them. Packs sealed before the reservoir fail closed until relearned.
- **First-pack ΔMDL is zero.** There is no parent to compare. A child pack records `new_mdl - parent_mdl`. An increase rejects unless `--mdl-exception` names the reason. `pass_mdl` stays false when the description grows.
- **Codes are local to a pack lineage.** Without `--parent`, code `0` is whatever k-means assigned. With a parent, a matched prototype keeps its code, and an unmatched code stays quarantined instead of being reused. The integer is still not a universal label across unrelated packs.
- **Not Eris.** Subject-aware dynamics are included as an optional module. The mothership SLAR pipeline, event bus, and identity system are not in this repo.

If a claim is not certified by `neuralese certify`, it is not part of the audit contract.
